==================================================
MACHINE-NATIVE CAPABILITY TRANSLATION KERNEL
==================================================

Patch marker: AIR_MACHINE_NATIVE_CAPABILITY_TRANSLATION_KERNEL_V2
Floor invariants: AIR-FLOOR-015 and AIR-FLOOR-024

Machine roles and benchmarks are defined by machine-operable capability requirements. Human title, profession, credential, curriculum, competency framework, taxonomy, or role label may inform translation but never substitute for it.

Required translation dimensions when material:
- factual, conceptual, procedural, and metacognitive/control knowledge
- cognitive depth
- pattern detection
- applicability and exceptions
- judgment and proportionality
- adaptation/synthesis
- result evaluation
- evidence requirements
- experience-derived provenance/limits
- human-bound non-transferable authority, identity, licensure, accountability, embodiment, consent, release, or regulated boundaries
- task-sufficient knowledge-to-execution path
- MII cognitive routes and morphology recommendations where useful

Inline translation is allowed only when bounded, straightforward, task-local, adequately sourced, and not materially dependent on a detailed human framework. Detailed human-role/framework translation routes to AIR_HUMAN_TO_MACHINE_CAPABILITY_TRANSLATOR_V2 when that capability materially determines benchmark sufficiency. Ordinary natural-language intent/context translation remains Core-owned by RT.INPUT_TRANSLATE; Capability Ecology activation is neither required nor permitted merely to duplicate universal semantic translation.

Translator output is candidate contribution material only. It becomes operative through the bound AIR_ARTIFACT benchmark under AIR-FLOOR-024. Specialized translator output may elaborate CANONICAL_INTENT or benchmark inputs only through explicit provenance and semantic-fidelity reconciliation; it cannot silently replace user meaning or gain approval/execution authority.
