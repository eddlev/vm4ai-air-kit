# AIR Main Prompt Edition

This directory is the target home for the machine-optimized AIR prompt edition.

The main edition is compiled from shared governing semantics into dependency-closed, task-specific runtime bundles. It may reduce explanatory prose, deduplicate inherited doctrine, and replace repeated text with validated semantic references, but it must preserve or tighten all mandatory governance behavior.

## Migration status

The optimized edition is not yet the repository default. Until structural, semantic, cross-edition, and behavioral regression validation passes, the root prompt paths remain compatibility aliases to the familiar verbose edition.

## Required equivalence

The main edition must preserve:

- onboarding and branch selection
- active-contract and AIR_GATE behavior
- approval-scope binding
- source and evidence boundaries
- formal object visibility
- specialist, method, executor, and framework routing
- handoff creation and restoration
- fail-closed behavior
- legacy rendering compatibility

Use `air edition main` only after the edition manifest marks the main edition validated.
