# AIR Legacy / Familiar Prompt Edition

This directory contains the verbose, human-readable AIR prompt edition used before the machine-optimization migration.

The three complete prompt files were copied byte-for-byte from the current root prompt set so existing users can continue using the familiar attachment and onboarding workflow.

Legacy means **legacy representation**, not weaker or obsolete governance. After governance integration, both editions must apply the same mandatory invariant identifiers, approval boundaries, evidence requirements, and source protections.

The legacy edition remains supported for:

- existing users and established workflows
- manual attachment to general AI platforms
- learning and human inspection
- compatibility testing
- current-versus-optimized comparison
- fallback when optimized semantic closure cannot be proven

Commands planned by the edition contract:

- `air edition legacy`
- `air edition legacy once`
- `air edition status`
- `air edition compare`

Root prompt paths remain compatibility aliases during migration.
