**AI work, carried forward.**

AIR (**AI Resource**) is a **prompt-based project-governance and continuity framework for sustained AI work**.

It keeps the active task, project boundaries, important decisions, evidence, approvals, and continuation state explicit so longer projects can stay focused and continue across sessions and compatible AI platforms.

You talk to AIR normally. AIR handles the project structure.

## Where AIR fits

AIR can work alongside the tools you already use.

- **MCP** connects AI applications with tools, data, and external capabilities.
- **Agents** can run or coordinate workflows and actions.
- **AIR** keeps the project contract and recorded working state explicit around that work.

AIR is not an autonomous agent or automation engine. It can govern ordinary AI work, tool-connected workflows, agents, automation, or combinations of them.

[Read the deeper explanation →](https://vm4ai.com/where-air-fits.html)

## Get started

Clone AIR Kit:

```bash
git clone https://github.com/eddlev/vm4ai-air-kit.git
cd vm4ai-air-kit
```

The command is the same on Windows, macOS, and Linux when Git is installed.

Load the five AIR Foundation files from [`prompts/`](prompts/):

```text
AIR_CORE_RUNTIME.md
AIR_CONTROL_SURFACE.md
AIR_GOV.md
AIR_DEFAULT_STARTER_PROFILE.json
AIR_HANDOFF_CARD_TEMPLATE.json
```

Then send:

```text
Start a new AIR project.
```

AIR validates the Foundation and starts onboarding.
