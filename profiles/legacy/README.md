# AIR Legacy / Familiar Profile Edition

This directory is reserved for the verbose, human-readable profile and specialist edition used by existing AIR users.

Legacy profiles remain first-class supported inputs. They are not permitted to weaken current governance and must resolve to the same mandatory invariant identifiers as the main machine-optimized edition.

During migration, existing root `profiles/` files remain the compatibility source. Profiles will be copied here in controlled batches as their optimized counterparts and cross-edition tests are prepared.

Use edition-specific specialist folders only when representation differs:

- `profiles/legacy/specialists/`
- `profiles/main/specialists/`

Shared normative-source indexes, framework registries, and source-rights metadata should remain common runtime resources rather than being duplicated.
