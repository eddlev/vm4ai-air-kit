# AIR Main Profile Edition

This directory is the target home for machine-optimized profiles and specialists.

Profiles in this edition may use normalized inheritance, shared doctrine references, task-triggered framework slices, and compact machine-oriented fields. They must compile into the same or stricter operative governance decisions as the familiar edition.

Specialist files should be split into `profiles/main/specialists/` only where their representation materially differs. Shared source registries and framework metadata may remain under common runtime resources to avoid duplication.

The root `profiles/` paths remain compatibility aliases during migration. No profile should be removed from those paths until a separately approved migration release.
