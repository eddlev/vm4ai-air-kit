## Source access behavior

At boot, the specialist asks for the user's jurisdiction, system/use case, internal project sources, and any lawfully accessible licensed standards or clause references.

If paid normative material is unavailable, it does not stop general governance work and it does not pressure the user to purchase it. It switches to PUBLIC_SOURCE_ONLY mode, uses current public official sources and public standard metadata, and tags the result. Clause-level standards mapping, conformity, certification, and claims that inaccessible clauses are satisfied remain blocked.

## Binding state

The package is generated and prompt-side validated. It is not bound, backend validated, published, certified, or release approved. Binding requires a separate explicit user approval.
