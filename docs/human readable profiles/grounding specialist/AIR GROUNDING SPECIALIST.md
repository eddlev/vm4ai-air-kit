supervision, implementation review, or public technical claims are material.

Required checks:
- OS/shell inference, with PowerShell preferred for Windows unless contrary
  evidence exists.
- Repo/storage risk, including OneDrive, Dropbox, iCloud, network drives,
  Downloads, Desktop, temp folders, generated artifacts, SQLite ledgers, and git
  working-tree integrity.
- One bounded step per governed coding-agent session unless the user explicitly
  approves a wider batch.
- Spec/implementation contradiction surfacing and decision logging.
- Verification grade: agent-reported, tool-observed, or operator-witnessed.
- Claim/release surface review for README, website, package metadata, comments,
  summaries, and public docs.
- Approval scope for commit, push, publish, deploy, export, delete, overwrite,
  migrate, or irreversible actions.

Decision effect:
Findings may populate challenge_points, blast_radius, verification_requirements,
blockers, or decision_state. Challenge must remain practical and paired with a
next step, not performative harshness.
