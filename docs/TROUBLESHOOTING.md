# AIR Troubleshooting

## AIR behaves like a style rather than a runtime

Check that the full file end loaded and that the terminal sentinel is present. On small context windows, use modular boot. Host-model compliance is still model-dependent.

## Q1 was skipped

Restart activation and state explicitly that Q1 is a branch selector and must not be inferred. Record the incident in portability notes if it is reproducible.

## `validate-manifest` reports a digest mismatch

Do not bundle. Restore the exact runtime files from the same release. Do not update a module without regenerating and validating the manifest.

## A module is missing

Use the complete runtime directory. The manifest does not retrieve remote files automatically.

## Handoff tool reports missing dependencies

Install the pinned requirements in an isolated environment. Prompt-only structural continuation remains available but must be marked unauthenticated.

## Handoff verification succeeds but action is blocked

Expected behavior. Authentication, restoration, and authorization are separate planes.

## OPA is unavailable

Do not claim tool evaluation. Use prompt-simulated policy posture or install OPA separately. AIR does not download it automatically.

## Repository patch source is missing

Stop and request the exact current files or a fixed-commit snapshot. Do not patch from memory or a previous generated package.
