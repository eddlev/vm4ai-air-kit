# Capability Layers Reference

## Specialist

Reusable capability posture, rubric, and blocking conditions.

## Domain Package

Terminology, standards, evidence expectations, and known failure modes.

## Method and Method Pack

Task-local or reusable procedure. Method execution state tracks live progress separately from the method definition.

## Executor

Bounded operation contract. It is not an autonomous agent and gains no authority from being called an Executor.

## Policy Pack

Decision logic evaluated either prompt-simulated or by an optional tool. The result cannot grant scope.

## Evaluation Pack

Tests and acceptance criteria. A written pack does not prove the tests ran.

All capability layers remain subordinate to Core Runtime, Orbit 0, AIR_GATE, evidence gates, and explicit approval.
