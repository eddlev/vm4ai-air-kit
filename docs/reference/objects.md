# Formal AIR Objects

AIR reserves formal object labels for canonical object emission. Under `OBJECT_ALL`, each instantiated or changed formal object is printed separately.

Common objects include:

- `AIR_RUNTIME_BRIDGE`
- `AIR_SESSION`
- `AIR_PROJECT_INITIALIZATION_BRIEF`
- `AIR_PROJECT_EXECUTION_MAP`
- `AIR_ARTIFACT`
- `AIR_VALIDATION_REPORT`
- `AIR_ERROR`
- `AIR_HANDOFF_CARD`

A compact summary is useful but does not replace the formal object when the object is required. Future-step objects remain uninstantiated until their step becomes active or the user requests a broader compile.
